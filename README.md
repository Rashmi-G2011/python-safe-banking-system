🏦 Safe Banking System

Overview

Safe Banking System is a beginner-friendly Python console application that simulates basic banking operations using Object-Oriented Programming (OOP). The application allows users to manage an account by checking their balance, depositing money, and withdrawing funds through a simple menu-driven interface. It also includes input validation and exception handling to provide a smooth user experience.

---

Features

- Create a bank account with an initial balance
- Check the current account balance
- Deposit money securely
- Withdraw money with insufficient balance protection
- Validate user inputs
- Handle invalid entries using exception handling
- Simple and interactive menu-driven interface
- OOP-based design using a "BankAccount" class

---

Technologies Used

- Python 3

---

How to Run

1. Ensure Python 3 is installed on your system.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the program:

python safe_banking_system.py
